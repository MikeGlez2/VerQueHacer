# Contexto del proyecto

- Entorno: WordPress en WAMP (local).
- Tema activo: `astra-child` en `wp-content/themes/astra-child`.
- Objetivo: Nueva versión de wwww.verquehacer.com, tema preparado para posicionamiento Google e IA, mejorar SEO técnico.

## Stack

- PHP 7.x / 8.x
- WordPress versión X.X
- CSS clásico (sin Tailwind).
- JS vanilla (o indica librerías si las usas).

## Convenciones

- No romper compatibilidad con plugins actuales.
- Mantener estructura de plantillas existente.
- Priorizar rendimiento y limpieza de código.
